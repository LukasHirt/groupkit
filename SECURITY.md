# Security Policy

## Supported versions

groupkit is pre-1.0 and moves quickly. Security fixes go into the latest
release only. Until the first release is tagged, they go into `main`.

## Reporting a vulnerability

Please report security vulnerabilities privately via
[GitHub Security Advisories](https://github.com/LukasHirt/groupkit/security/advisories/new)
rather than a public issue.

You should expect an initial response within a few days. Once a fix is
ready, we'll coordinate disclosure timing with you.
